# Story-Tables
# Story Frontend

Фронтенд для системы Story на React + TypeScript (Create React App).

## Запуск

```bash
npm install
npm start
```

## Сборка для продакшена

```bash
npm run build
```

## Docker

Фронтенд собирается в Docker через `Dockerfile` в этой директории и раздаётся через nginx.
